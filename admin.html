📋 トークンの取得手順

  1. github.com → Settings → Developer settings → Fine-grained tokens を開く
  2. 「Generate new token」をクリック
  3. Repository access で「Only select repositories」を選び taniguchi-source/jdsf-seibu を選択
  4. Permissions → Repository permissions → Contents を 「Read and write」に設定
  5. 「Generate token」で作成し、表示されたトークンをコピー
