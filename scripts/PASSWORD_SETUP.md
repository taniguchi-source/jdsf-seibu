# パスワード管理：私用シートへの切り替え手順（ブロック事務局用）

セキュリティ改修は完了しています（全16サイトでサーバー側セッション認証・PWはハッシュ保存・
未ログインの書き込みは拒否）。この文書は **最後の仕上げ**＝「あなただけが見られる非公開シートで
全パスワードを一元管理する」ための手動セットアップ手順です。

## いま起きること（仕組み）
- あなたが**非公開シート**でPWを編集 → メニュー **🔐 パスワード管理 → 全サイトへ反映** で各サイトへ適用。
- 各府県の担当者が自分の画面でPW変更 → **自動でこの非公開シートに書き戻し**（常に最新）。
- 公開GASからの平文PW取得は**停止**（secret必須化）＝最後の穴も塞がる。

---

## 手順（一度だけ）

### 1. 非公開シートを作る
1. Googleドライブで **「HP用資料」を開く → ファイル → コピーを作成**。
2. 名前を「HP用資料（PW管理・非公開）」等に。
3. **共有 → 「制限付き」**（自分のみ）に設定。他の人には共有しない。
4. URLの `/d/●●●●/` の **●●●●（シートID）** を控える。

### 2. GAS にマスター秘密を設定
1. Apps Script「お問い合わせ フォーム処理」を開く。
2. **プロジェクトの設定（⚙）→ スクリプト プロパティ → プロパティを追加**。
3. プロパティ名：`AUTH_SECRET`
4. 値：ローカルの **`scripts/.master_secret` ファイルの中身**（1行の長い文字列）をそのまま貼り付け。

### 3. GAS を差し替えて再デプロイ
1. `scripts/gas_contact.js` の中身を全部コピーし、Apps Script エディタに貼り付け（既存を置き換え）。
2. 冒頭の `var SHEET_ID = '...';` を **手順1で控えた新シートID** に変更。
3. **デプロイ → デプロイを管理 → 既存を選び ✏️ → 新バージョン → デプロイ**（※URLは変えない）。
4. **メニューを有効化（一度だけ）**：このGASは standalone（シート非紐付け）のため、
   エディタで関数リストから **`installMenu` を選んで ▷ 実行**（初回は認可を許可）。
   その後、新シートを再読み込みするとメニュー **「🔐 パスワード管理」** が出ます。
   - ※メニューを使わず、ローカルの `python scripts/set_passwords.py --sub <府県> --inherit` でも
     シート→サイトへ反映できます（メニューが不要ならこの手順4は省略可）。

### 4. 動作確認 → 旧シート削除
- **反映テスト**：新シートで任意府県のM/N（管理/構築PW）を変更 → メニュー **🔐 → 全サイトへ反映** →
  その府県サイトに新PWでログインできるか確認。
- **書き戻しテスト**：どこかのサイトの「🔑 パスワード変更」で変更 → 新シートの該当行 M/N が更新されるか確認。
- 問題なければ **旧「HP用資料」を削除**（またはPW列 M/N を空に）。
  - ✅ **安全確認**：このGASは standalone（シート非紐付け）なので、旧シートを削除しても
    GAS本体・ウェブアプリURLは消えません。**ただし切替（SHEET_IDを新シートに変更＋再デプロイ）を
    済ませ、お問い合わせ試験に合格してから**削除すること（切替前に消すとお問い合わせも止まります）。
  - ⚠️ 新シートは「HP用資料」の**丸ごとコピー**（G/H/I・J〜N・Q〜X の全列）であること。
    PW列(M/N)だけ移すと、お問い合わせ振り分け（G/H/I・Q〜X）が壊れます。

## 日々の運用
- **あなた**：非公開シートで M（管理PW）/ N（構築PW）を編集 → **🔐 → 全サイトへ反映**。
- **各府県担当者**：各サイトの「🔑 パスワード変更」で自分の府県だけ変更（自動でシートにも反映）。
- PWは各サイトにハッシュで保存（誰も現PWは読めない）。**シートが「現在のPW一覧」**の役割。

## メモ
- 島根・lesson は現行の短いPWのまま（担当者へ8文字以上への変更を依頼予定）。
- マスター秘密（`scripts/.master_secret` / GitHub Secret `AUTH_MASTER_SECRET` / GAS `AUTH_SECRET`）は3か所同値。
- 手動リセット（担当者がPW失念時）：`python scripts/set_passwords.py --sub <府県> --admin "新PW"` でも可。
